# Quiz App – Application Android de Quiz

Application mobile Android native (Java) proposant des quiz à choix multiples avec suivi du score.

## Fonctionnalités

- Questions à choix multiples avec navigation entre les écrans (Activities)
- Calcul et affichage du score du joueur
- Interface utilisateur native Android

## Stack technique

- Java, Android SDK
- Gradle (Kotlin DSL)

## Lancer le projet

1. Ouvrir le dossier dans Android Studio
2. Laisser Gradle synchroniser les dépendances
3. Lancer l'application sur un émulateur ou un appareil Android connecté

## Contexte

Projet réalisé pour s'exercer au développement mobile natif Android en Java.
